# LearningApp

Plateforme web d'apprentissage des mathématiques par manipulation directe (style Graspable Math) : on saisit un terme d'une équation et on le fait glisser ; les opérations inverses s'appliquent automatiquement. Contenu pédagogique en français, Phases 1–18 (de l'arithmétique aux méthodes d'expert, algèbre linéaire — matrices dans l'AST comprises, multivariable 3D, Fourier, Maxwell, dérivation/intégration par gestes, probabilités, Laplace, nombres complexes — produit/conjugué par gestes compris, moindre action et fluides, chaos, quantique avec spin σx/σy, relativité avec boost de Lorentz, théorie des nombres jusqu'à RSA et φ d'Euler, groupes — les symétries du carré D₄ dans l'AST, l'art de la preuve — récurrence/absurde/tiroirs par substitution) + un mode examen quotidien (« Défi du jour ») + des « expéditions » (problèmes rédigés multi-étapes à indices progressifs). **`ROADMAP.md` est la carte maîtresse** : 26 stations A→Z jusqu'au niveau Humanity's Last Exam, avec les paliers techniques. Voir aussi les 3 fichiers `*.md` racine (recherche Gemini).

## Stack

- React 19 + TypeScript + Vite, 100 % client (progression en `localStorage`).
- `@cortex-js/compute-engine` (MathJSON) : vérité sémantique, vérification d'équivalence.
- KaTeX : rendu LaTeX des cours (`CourseView`/`MathText` : blocs `math` + segments `$...$` + `**gras**`) — les équations manipulables sont rendues par notre propre renderer React (`src/components/Equation/`).

## Commandes

- `npm run dev` / `npm run build` / `npm test` (vitest) / `npm run lint` (oxlint)
- Node via nvm : `export PATH=~/.nvm/versions/node/v20.20.2/bin:$PATH`

## Architecture

- `src/core/` — logique pure, **zéro dépendance React**, testée par vitest :
  - `ast.ts` : types MathJSON + navigation par chemin (path).
  - `rules/` : moteur de règles de transformation ; chaque règle produit les manipulations légales pour une sélection donnée. C'est le cœur pédagogique du projet. `derive.ts` : la dérivation par taps (nœud `['D', corps, 'x']` — constante, puissance, linéarité, produit, sin/cos/exp/ln + règle de la chaîne pour les composés). `integrate.ts` : primitives par taps (`['Int', corps, 'x']`) + théorème fondamental en un geste (D(∫f)→f, ∫(f′)→f) + intégration par parties (`int-parts`) + substitution linéaire (`int-linear`). `laplace.ts` : table de Laplace par taps (`['LT', f]` → fonctions de s ; `['ILT', F]` pour le retour ; `lt-derive`/`lt-derive2` : ℒ{y′}=sY−y₀, ℒ{y″}=s²Y−sy₀−v₀ ; `partial-fractions` : éléments simples ; `ilt-cos`/`ilt-sin` : retours oscillants — pipeline EDO 100 % gestuel jusqu'au 2ᵉ ordre). `complex.ts` : cycle des puissances de `i` (simple symbole de l'AST) + formule d'Euler déplier/replier + `exp-power` ((e^θ)ⁿ=e^{nθ}, racines de l'unité). `trig.ts` : valeurs exactes du cercle unité (sin/cos de 0, π/6 … 2π) par taps. `matrix.ts` : matrices dans l'AST (`['Mat2',a,b,c,d]` ligne par ligne, `['Vec2',x,y]`) — `MatVec` étale « ligne × colonne » en un tap (les entrées se calculent ensuite par gestes), `MatMul` = composition, `Det` se déplie en ad−bc, `VecScale` = λv (calculé d'un coup si tout est numérique) ; Iv=v en un tap. `nombres.ts` : algorithme d'Euclide par taps (`['Gcd',a,b]` → un pas par geste), lecture de l'horloge (`['Mod',a,n]`), réduction modulaire en chemin (un entier ≥ n dans un Mod se réduit — jamais dans un exposant ni dans le modulus), φ d'Euler (`['Phi',n]` : premier, puissance de premier, multiplicativité). `groupes.ts` : le groupe D₄ dans l'AST — les 8 symétries du carré sont des symboles (`idS`,`r90`…,`sH`…), `['Compose',...]` se réduit d'un tap (paire la plus à droite, table de Cayley calculée en forme normale r^k·f), `['Inv',g]` + chaussettes-chaussures (a∘b)⁻¹ = b⁻¹∘a⁻¹. `complex.ts` porte aussi le conjugué (`['Conj',z]` se déplie : somme, produit, i→−i) ; `cancel.ts` les gestes `combine-numbers` (deux nombres d'un produit mixte) et `negate-out` (le signe sort du produit) qui rendent (a+bi)(c+di) entièrement manipulable. `preuves.ts` : l'art de la preuve par le geste de substitution (`['Subst', corps, variable, valeur]` remplace d'un tap toutes les occurrences — moteur de la récurrence (instancier P(1), injecter l'hypothèse P(k)), de l'absurde (a→2c dans a²) et des tiroirs ; tête opaque pour que le CAS ne devine pas le résultat).
  - `engine.ts` : wrapper compute-engine (équivalence, simplification). `reachesGoal` : garde structurelle si l'expression contient une tête opaque (`D`, `Int`, `LT`, `ILT`, têtes matricielles `Mat2`/`Vec2`/`MatVec`/`MatMul`/`Det`/`VecScale`, `Gcd`, `Mod`, `Phi`, `Conj`, `Compose`, `Inv`, `Subst` — sinon le CAS résoudrait à la place de l'élève) ; `strictGoal` sur un exercice = comparaison structurelle seule (pour les exercices dont le but EST le calcul, ex. p = 3/6 → 0,5) ; la comparaison structurelle est commutative pour `Add`/`Multiply` (`sameExprUpToOrder` : 3+3i ≡ 3i+3).
  - `progress.ts` : progression + localStorage. `quest.ts` : Défi du jour — tirage quotidien déterministe (PRNG semé par la date) de 5 exercices à `goal` dans 5 phases différentes, série de jours consécutifs/record en localStorage. `expedition.ts` : ensemble des expéditions terminées (localStorage).
- `src/components/Equation/` — renderer AST → React (chaque nœud porte `data-path`) + couche drag (Pointer Events natifs, machine à états idle/dragging/drop/rebound). Rend aussi les matrices (`Mat2` en grille 2×2 entre crochets, `Vec2` en colonne), `pgcd(a, b)`, `a mod n`, `φ(n)`, le conjugué (barre au-dessus), les compositions de symétries (a ∘ b, g⁻¹, glyphes 𝟙/r/r²/r³/h/v/d/d′).
- `src/components/Graph/` — graphe canvas des deux côtés d'une équation ; l'intersection (= solution) reste immobile pendant les manipulations.
- `src/components/Physics/` — simulations et explorateurs canvas : cinématique 1D, tangente, aire, champ de vecteurs (+ mode gradient avec potentiel en fond), ressort (EDO), vecteurs 2D draggables, matrice 2×2 (grille transformée, det, vecteurs propres), série de Fourier (Gibbs visible), `Surface3D` (renderer 3D canvas maison : projection yaw/pitch + painter's algorithm — pas de Three.js tant que ça suffit), cercle unité (sin/cos déroulés), champ de directions d'EDO (clic = condition initiale, RK2), planche de Galton (binomiale), Bayes (population 10 000 points), sommes de Riemann (curseur n), plan des pôles de Laplace (pôle draggable ↔ réponse temporelle), plan complexe (z et w draggables : modules multipliés, angles additionnés), épicycles (cercles tournants e^{ikt} qui dessinent le créneau), arbre de probabilité pondéré (3 curseurs, feuilles multipliées), racines de l'unité (polygones/étoiles sur le cercle), corde vibrante (modes propres, corde pincée), symétries du carré (coins colorés, boutons r/h/v/d/d′, composition écrite en direct), onde EM (E ⊥ B animés), domain coloring (f(z) peinte, ImageData), marches aléatoires (±√t, histogramme), action de Lagrange (chemin déformable, S en direct), fluide 2D Navier-Stokes (« stable fluids » de Stam 64×64, souris = encre), puits quantique (ψₙ en rotation complexe, superposition), double pendule (RK4, jumeau divergent), espace des phases (flot hamiltonien, séparatrice), effet tunnel (ψ évanescente, T en direct), diagramme de Minkowski (axes en ciseaux, simultanéité relative), file de dominos (la récurrence : pousser le 1ᵉʳ, chacun fait tomber le suivant).
- `src/components/Lesson/CourseView.tsx` — rendu des cours riches (`CourseBlock` : p / math / example / callout idea|warn|story).
- `src/content/` — les leçons sont des **données** typées (`schema.ts`), pas du code. 85 leçons, Phases 1–18 (`lessons.ts` = Phases 1–5, `phases678.ts` = Phases 6–9, `complements.ts` = compléments D/G/L + Phase 10 probabilités, `phase11.ts` = intégration par gestes + Laplace, `phase12.ts` = règle de la chaîne + Phase 12 nombres complexes, `approfondissements.ts` = par parties + arbres/espérance + ℒ{y′} + racines de l'unité, `horizons.ts` = substitution + onde EM + corde + marches + 2ᵉ ordre/éléments simples + domain coloring + Phase 13 action/fluides, `quantique.ts` = chaos + espace des phases + Phase 14 Schrödinger/Heisenberg, `relativite.ts` = effet tunnel + Phase 15 Minkowski/dilatation, `matrices.ts` = Av/AB/det/vecteurs propres par gestes (Phase 7) + spin de Pauli (Phase 14) + boost de Lorentz (Phase 15), `nombres.ts` = Phase 16 Euclide/horloge/Fermat/RSA + φ d'Euler/inverse modulaire, `complexe.ts` = produit complexe/conjugué (Phase 12) + σy (Phase 14), `groupes.ts` = Phase 17 symétries du carré/Cayley/inverses/Klein, `preuves.ts` = Phase 18 récurrence (dominos)/absurde (√2 irrationnel)/tiroirs (collisions modulaires) par le geste de substitution). `expeditions.ts` = 3 problèmes rédigés multi-étapes à indices progressifs (`hints[]` sur `Exercise`, champ `depth` pour la vérification BFS des exercices longs).
- `src/pages/` — Accueil (carte de progression), Lesson, Quest (Défi du jour : 5 exercices en mode examen sans indices, chrono, série), Expedition (problème multi-étapes : récit, indices progressifs, épilogue), Playground (chargé en lazy : MathLive est lourd).
- `src/core/sound.ts` + `prefs.ts` — sons WebAudio synthétisés, thème clair/sombre, préférences localStorage.
- `.github/workflows/` — CI (lint+test+build) et déploiement GitHub Pages (base `./` + hash routing : aucun rewrite nécessaire). Activer Settings → Pages → Source « GitHub Actions » une fois le repo créé.

## Principes

- Toute mutation d'AST issue d'un geste doit être validée : règle applicable + équivalence vérifiée via compute-engine.
- Geste illégal → rebond visuel + indice, jamais de message d'erreur punitif.
- Garder `core/` exhaustivement testé (matrice de cas légal/illégal par règle).
- Tout nouvel exercice avec `goal` doit être vérifié résoluble par gestes : `npx tsx scripts/verify-lessons.ts [ids…]` (BFS sur `legalMoves`+`reachesGoal`) ; le LaTeX des cours : `npx tsx scripts/verify-latex.ts`.
- Besoin avant solution : chaque palier technique (3D, workers, WASM…) n'entre que quand une station de `ROADMAP.md` l'exige.
